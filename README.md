# MANGA HUB

Application mobile iOS / Android construite avec Expo et React Native.

## Première version
- Interface sombre avec accents violets
- Accueil, catalogue, recherche et fiches manga
- Bibliothèque personnelle et suivi manuel de lecture
- Sauvegarde locale sur l'appareil

## Lancer dans Expo Go depuis GitHub Codespaces
Le dépôt est configuré pour installer ses dépendances puis démarrer Expo en mode tunnel.

Dans le terminal du Codespace, exécuter une seule commande :

```bash
npm run codespaces
```

Quand Expo affiche le QR code ou le lien du projet, ouvrir le lien Expo Go sur l'iPhone. Si l'iPhone et le Codespace sont sur le même appareil, utiliser le lien de développement affiché dans le terminal plutôt que de scanner le QR code.

## Versions
- Expo SDK 58
- React Native 0.88
- React 19
- AsyncStorage 2.2

## État et limites
Cette version est une base de développement, pas une application publiée ni un fichier iPhone installable. Les titres, nombres de chapitres et statuts sont des données de démonstration à vérifier. Les couvertures sont temporaires. Les comptes, la synchronisation cloud, les nouveautés en direct et les liens de lecture vérifiés restent à développer. Aucun scan ou chapitre protégé n'est hébergé.
